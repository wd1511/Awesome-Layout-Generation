# Selected papers

## Datasets

### Common Datasets

- [Rico](https://www.interactionmining.org/archive/rico) · Android screens and their interface hierarchies
- [PubLayNet](https://github.com/ibm-aur-nlp/PubLayNet) · scientific pages annotated with text, lists, tables and figures
- [Magazine](https://huggingface.co/datasets/creative-graphic-design/Magazine) · magazine pages with annotated text and image regions
- [Crello](https://huggingface.co/datasets/cyberagent/crello) · layered design templates with text, images and vector elements
- [DocLayNet](https://huggingface.co/datasets/ds4sd/DocLayNet) · human-annotated page layouts across document types
- [PKU PosterLayout](https://mipl.pku.edu.cn/PosterLayout/) · poster backgrounds with text, logo and underlay layouts
- [CGL v1](https://tianchi.aliyun.com/dataset/142692) · advertising posters for content-aware layout generation
